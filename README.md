# Smash'It — Fundão | Menu Digital

Site estático, preparado para GitHub Pages.

## Ficheiros
- `index.html` — menu e estrutura do site
- `styles.css` — design responsivo
- `script.js` — tabs e navegação
- `assets/logo.png` — logo fornecido

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie todos os ficheiros deste projeto para o repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`.
6. Guarde e aguarde alguns instantes pelo link do site.
